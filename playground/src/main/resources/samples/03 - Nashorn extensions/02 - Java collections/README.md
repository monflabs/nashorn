# Java collections

`java.util.List` and `java.util.Map` are linked so that a script can treat them as arrays and objects: index a list, put into a map by key, iterate either with `for...in`, `for each...in` (a Nashorn extension) or `for...of`.

`Java.from` makes a JavaScript array out of any Java collection or array; `Java.to` converts a JavaScript array to a Java array or `List`.
