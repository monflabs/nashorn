# Strings

String values against String objects, and the everyday methods: `slice`/`substring`/`substr`,
case mapping, `includes`/`startsWith`/`endsWith` (ES2015), `trim`, `split`, `replace`, `repeat`
and `padStart`-era template literals with `String.raw`. Note the comments where a method is
newer than ES2017 - `trimStart` and `replaceAll` are shown with their regular-expression
equivalents instead, because this engine implements ECMAScript 2017 and stops there on purpose.
