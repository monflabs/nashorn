# Variables and types

The seven types of ES2017 - undefined, null, boolean, number, string, symbol and object - and the
three ways to declare a name: `var`, function scoped and hoisted; `let` and `const`, block scoped.
The tail of the sample walks the classics of coercion (`'3' * '4'`, `[] + {}`, `null == undefined`)
because knowing how a dynamic language bends its types is half of reading its code.
