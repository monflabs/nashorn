# Arrays

The array workhorses - `map`, `filter`, `reduce`, `find`, `some`, `every`, `sort`, `slice` and
their friends - applied to one running example. Everything here is ES5.1 or ES2015 standard
library; when you need to hand an array to Java or borrow one back, that is `Java.to` and
`Java.from`, shown in the *Nashorn extensions* category.
