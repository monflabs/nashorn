# ---- Annex B B.3.3 indirect-eval "existing var update" ----
# The eight below are one shape: an indirect eval whose block-level function

# writing the global object outright instead - CreateGlobalVarBinding read

# ---- ECMAScript 2018 async iteration: microtask-tick exactness ----
# Async generators, for-await-of, yield* delegation and the async-from-sync

# ordering of microtask turns - the getter-tick sequence of a yield*'d return,

# engine an async body runs on a virtual thread and its completion reaches the
# job queue through the event loop rather than as a synchronous microtask, so

# it exactly is a change to how every async result is delivered, not a local fix.
